# Status Code Explorer

Buscador interativo de codigos HTTP com significado, categoria, exemplo e contexto de uso.

## Funcionalidades

- Busca por numero, nome, categoria e contexto.
- Filtros por familias HTTP: 1xx, 2xx, 3xx, 4xx e 5xx.
- Painel de detalhes com exemplo copiavel.
- Historias visuais para entender cada familia de status.
- Interface responsiva e animada.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
